A few things worth knowing
This is a project-specific SFV v1 format, not compatible with openssl enc. It uses native WebCrypto, PBKDF2-HMAC-SHA-256 (600,000 iterations), a fresh random salt and nonce, and a 128-bit authentication tag. PBKDF2 is not memory-hard. Authentication is not a signature or proof of identity.
Maximum input: 16 MiB per file or 1 MiB UTF-8 text. Processing is in memory, not streamed. Cancel discards work; browser cryptographic operations may not be interruptible. Clear removes references and downloads’ object URLs on a best-effort basis, not secure memory erasure or deletion of saved files.
No telemetry, secret persistence, remote fonts, or external scripts. Hosting still receives normal page requests. A compromised origin, device, browser, or extension can observe secrets. This project has not been independently audited; use established audited local tools for high-risk needs. Decrypted files may be unsafe: download only when intended and open with care.
